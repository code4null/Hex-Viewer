# Hex Viewer

A simple Hex Viewer built with C++.

## About

This project aims to provide a practical way to inspect files at the byte level by displaying their contents in hexadecimal format.

The project is being developed incrementally as a personal learning project, with a focus on understanding file handling, binary data, memory management, and low-level programming concepts in C++.

## Project Goals

- Read files in binary mode.
- Display file contents in hexadecimal format.
- Display corresponding ASCII characters.
- Navigate through file contents.
- Handle files of different sizes efficiently.
